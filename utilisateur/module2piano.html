Accords de Base + Travail des Mains

1- Qu'est-ce qu'un accord ?

Un accord est un ensemble de plusieurs notes jouées en même temps.

Exemple :

  • Do majeur = Do - Mi - Sol

2- Les accords majeurs de base

A apprendre absolument :

  • Do majeur → Do – Mi – Sol
  • Fa majeur → Fa – La – Do
  • Sol majeur → Sol – Si – Ré

Travail des mains au Piano

Main droite (MD)

Rôle :

  • Jouer la Mélodie
  • jouer les accords

Position :

  • Pouce → fondamentale
  • Majeur → tierce
  • Auriculaire → quinte

Main Gauche (MG)

Rôle :

  • Jouer le notes graves (basses)
  • Donner le rythme et le stabilité
  • Accompagner la musique

Au début, la main gauche joue :

  • Une seule note = la fondamentale de l'accord

Exemple :

  • Accord de Do → MG joue Do
  • Accord de Fa → MG joue Fa
  • Accord de Sol → MG joue Sol

Principe simple :

  • Main gauche → note seule
  • Main droite → accord

Exemple :

  • MG : Do → MD : Do - Mi - Sol
  • MG : Fa → MD : Fa - La - Do
  • MG : Sol → MD : Sol - Si - Ré

Résultat : Son complet et Musical.

Résumé du module

Les accords

Un accord est un ensemble de plusieurs notes jouées en même temps. Accords majeurs de base : Do majeur (Do–Mi–Sol), Fa majeur (Fa–La–Do), Sol majeur (Sol–Si–Ré).

Main droite

Joue la mélodie et les accords : pouce sur la fondamentale, majeur sur la tierce, auriculaire sur la quinte.

Main gauche

Joue les notes graves et donne le rythme. Au début, elle joue une seule note : la fondamentale de l'accord (ex. accord de Do → MG joue Do).

Progression et rythme

Progression très courante : Do → Fa → Sol → Do. Rythme simple : 1 accord = 4 temps, compté 1-2-3-4.

À venir dans le module 3

Accords mineurs, accords de 7e, renversements et accompagnement plus avancé.
