EXERCICES PRATIQUES PIANO

Exercice 1 : Reconnaître le Clavier

Objectif : Se repérer facilement sur le piano

Consigne :

  • 1- Trouve les groupes de 2 touches noires
  • 2- Juste à gauche : c'est la note Do
  • 3- Répète sur tout le clavier

A faire :

  • Trouver 5 Do différents
  • Lire à voix haute : Do - Re - Mi - Fa - Sol - La - Si

Exercice 2 : Position des doigts (sans jouer)

Objectif : Habituer la main à la bonne forme

Consigne :

  • 1- Pose ta main droite sur le Clavier
  • 2- Chaque doigt sur une touche blanche
  • 3- Garder les doigts arrondis comme une balle

A Verifier :

  • Poignet détendu
  • Doigts pas plats
  • Main relax

Faire pendant 1 à 2 minutes

Exercice 3 : Tenue de posture

Objectif : Avoir une bonne position du corps

Consigne :

  • 1- Assieds-toi droit
  • 2- Ne touche pas au piano
  • 3- Place tes mains comme si tu allais jouer

A Verifier :

  • Dos droit
  • Epaules détentues
  • Pieds bien au sol

Tenir la position pendant 1 à 2 minutes

Exercice 4 : Premier contact avec les touches

Objectif : Jouez avec une bonne position

Consigne :

  • 1- Main droite sur Do - Re - Mi - Fa - Sol
  • 2- Joue lentement chaque note (1 doigt = 1 touche)

Doigté :

  • Pouce = Do
  • Index = Ré
  • Majeur = Mi
  • Annulaire = Fa
  • Auriculaire = Sol

A faire :

  • Monter : Do → Sol
  • Descendre : Sol → Do

Important :

  • Ne pas se presser
  • Garder la bonne posture

Exercice 5 : Contrôle du corps + mains

Objectif : Coordination posture + doigts

Consigne :

  • Refaire l'exercice 4
  • Mais en vérifiant :
    • Dos droit
    • Poignet souple
    • Doigt arrondis

Petit défi (Facultatif)

Trouve tous les Do du clavier sans regarder tes mains trop longtemps
